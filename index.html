목적: 개인 공부용 - VMware 리눅스 서버 설치 및 운영

1. 서버 구축 개요

VMware 가상 머신 환경에 리눅스(Ubuntu/CentOS 등)를 설치하여 외부에서도 접근 가능한 서버 환경을 구축하는 과정을 공부합니다.

가상화 VMware Workstation
OS Linux Distribution
서비스 Web/DB Server

2. 주요 단계별 가이드

1

가상 머신 생성

VMware에서 New Virtual Machine을 생성하고 리눅스 ISO 파일을 마운트합니다.

2

서버 패키지 설치

Apache, Nginx 등 웹 서버 소프트웨어와 필요한 라이브러리를 설치합니다.

3

외부 접근 설정 (Port Forwarding)

공유기 설정 및 VMware NAT 설정을 통해 외부 유저가 공인 IP로 접근할 수 있게 포트를 개방합니다.
